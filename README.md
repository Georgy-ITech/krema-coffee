# КРЕМА — интернет-магазин спешелти-кофе

React + Vite + TypeScript магазин обжарщиков спешелти-кофе с живыми фильтрами,
корзиной, оформлением заказа и страницами товара. Тёмный премиум-бренд «эспрессо»
с карамельным акцентом `#c8863c` и дисплейным шрифтом Unbounded.

Реализовано по [техническому заданию](docs/TZ-KREMA.md) (анализ рынка → ТЗ → реализация).

🔗 **Демо:** [krema-coffee.vercel.app](https://krema-coffee.vercel.app)

> AI-инструменты использовались для ускорения разработки. Архитектура, проверки,
> продуктовые решения и финальная реализация — авторская работа.

## Ключевые фичи

- **Свежесть как фича** — дата обжарки на каждом товаре («Обжарено N дней назад»),
  бейдж свежести, «ближайшая обжарка — вторник»
- **Конструктор покупки** — выбор помола (5) и веса (250 г / 1 кг) с пересчётом цены;
  варианты — отдельные позиции в корзине
- **Профиль вкуса** — шкалы кислотность/плотность/сладость + ноты
- **Каталог с фильтрами** — поиск, категория, обжарка, метод заваривания, цена, рейтинг;
  **состояние фильтров в URL** (ссылка шарится и переживает refresh)
- **Корзина** — Context + `useReducer` + `localStorage`, прогресс до бесплатной доставки
- **Оформление заказа** `/checkout` — доставка (СДЭК/Почта/самовывоз), оплата, промокод,
  инлайн-валидация без `alert()`, экран успеха (демо-режим)
- **Контент** — страницы доставки, обжарки, контактов; бегущая строка происхождений
- **Тема** dark/light с персистом, самохостовые шрифты `@fontsource`, `prefers-reduced-motion`
- **SEO** — per-page `<title>`/description, JSON-LD `Product`, `robots.txt`
- **Адаптив** — 3→2→1 колонки, полноэкранный hero, ноль горизонтального переполнения

## Архитектура

- `data/` — модель `Product` и слой доступа `catalog.ts` за абстракцией (под будущий API/CMS)
- `hooks/` — `useFilters` (URL-состояние), `useCartLines`, `useTheme`, `useMeta`
- `context/` — `CartContext` (варианты товара в ключе позиции)
- `components/` / `pages/` — UI и экраны, стили — SCSS-модули

## Разработка

