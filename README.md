# Overlay — Creative Assets Marketplace

Первый флагман на **Треке B** (React + Vite + TypeScript). Витрина маркетплейса
креативных ассетов (UI-киты, иконки, пресеты, шрифты, 3D, обои) с живыми фильтрами,
корзиной и детальными страницами. Акцент — pink `#ff2d78`, тёмный премиум-бренд.

## Что демонстрирует

- **React 19 + TypeScript** — компоненты, типизированная модель данных
- **Производное состояние** — фильтрация/сортировка через `useMemo` (`useFilters`)
- **Context + `useReducer`** — корзина с персистом в `localStorage`
- **React Router 7** — каталог `/` и страница товара `/product/:id`, scroll-to-top
- **Фильтры**: поиск, категории (multi), режим цены, слайдер макс. цены, рейтинг
- **Сортировка**: популярность / новизна / цена / рейтинг
- **Корзина-drawer**: количество, удаление, подытог, пустое состояние
- **Обложки товаров** — генерируются в SVG (мотив на категорию), ноль внешних картинок
- **Тема** dark/light с персистом (`overlay-theme`), самохостовые шрифты `@fontsource`
- **Адаптив**: 3 колонки → 2 → 1, без горизонтального переполнения

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка в dist/
npm run preview  # предпросмотр сборки
```
