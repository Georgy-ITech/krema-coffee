## 1. Цель документа и проекта

**Цель проекта:** превратить текущий добротный концепт в **уникальный, конверсионный
и запоминающийся** интернет-магазин спешелти-кофе уровня лучших игроков рынка РФ —
пригодный и как портфолио-флагман (демонстрация навыков React), и как реальный
коммерческий продукт под доработку с бэкендом.

**Цель ТЗ:** дать исполнителю исчерпывающий план — рыночный контекст, аудит текущей
версии, концепцию отстройки, функциональные и нефункциональные требования, этапы и
критерии приёмки, — по которому он выполнит реализацию без дополнительных уточнений.

## 2. Анализ рынка и актуальность (2026)

### 2.1. Рынок
Спешелти-кофе в РФ — устойчиво растущий сегмент: аудитория домашнего заваривания
расширяется, растёт спрос на свежую обжарку с доставкой и на подписки. Ключевая
ценность для покупателя — **свежесть, прозрачность происхождения и удобство повтора
покупки**. Продажи всё сильнее уходят в онлайн-витрины обжарщиков и подписочные модели.

### 2.2. Бенчмарки (на кого равняться)
- **Tasty Coffee** (shop.tastycoffee.ru) — 150+ SKU, развитая **подписка** с накопительной
  скидкой за регулярность, бесплатная доставка от порога, выбор помола, фильтры по вкусу
  и способу заваривания.
- **Torrefacto** (torrefacto.ru) — свежеобжаренный кофе, сильный сторителлинг обжарки и
  происхождения, регулярные релизы с датами обжарки.
- Общий уровень мировых обжарщиков (2026): дата обжарки на каждой карточке, tasting notes,
  выбор помола и веса, наборы-флайты для новичков, обучающий контент (гайды по завариванию).

### 2.3. Тренды e-commerce кофе 2026 (что уже стало стандартом)
1. **Дата обжарки на витрине** — прозрачность свежести убирает главное возражение.
2. **Выбор помола и веса (варианты товара)** — под эспрессо/фильтр/турку, 250/1000 г.
3. **Tasting notes + профиль вкуса** — ноты, шкалы кислотности/тела/сладости, «вкусовое колесо».
4. **Подписка** — интервал + скидка; удерживает и повышает LTV.
5. **Наборы-флайты / сэмплеры** — снижают порог первой покупки; по данным рынка дают
   до **+27% конверсии в первую подписку**.
6. **Обучающий контент** — гайды по завариванию, ноты, советы бариста (в 42% подписок как
   добавленная ценность) — оправдывает премиальную цену и повышает вовлечённость.

### 2.4. Вывод — как «КРЕМЕ» отстроиться
Не копировать сетку-каталог «как у всех», а сделать акцент на **свежести (дата обжарки +
счётчик), вкусовой прозрачности (профиль + колесо), персонализации (квиз-подбор) и
подписке**. Плюс сильный визуальный бренд (тёмный «эспрессо» + карамельный акцент,
крупная типографика Unbounded) — то, чем сухие каталоги конкурентов не блещут.

## 3. Целевая аудитория и цели

### 3.1. Персоны
- **«Осознанный новичок»** — попробовал спешелти в кофейне, хочет дома, но боится
  ошибиться с выбором. Нужны: подсказки по вкусу, наборы, гайды, квиз.
- **«Домашний энтузиаст»** — есть воронка/эспрессо-машина, знает вкусы. Нужны: фильтры по
  обжарке/методу/происхождению, помол, дата обжарки, быстрый повтор заказа/подписка.
- **«Подарок»** — ищет красивый набор. Нужны: наборы, подарочная упаковка, понятная витрина.

### 3.2. Бизнес-цели и метрики (KPI)
- Конверсия в корзину/заказ; средний чек; доля заказов с подпиской; доля наборов у новичков.
- Технические цели-прокси: Lighthouse Performance ≥ 90, Accessibility ≥ 95, ноль ошибок в консоли.

## 4. Аудит текущей версии (что уже есть)

**Стек:** React 19 + Vite + TypeScript, SCSS-модули, React Router 7, самохостовые шрифты
(`@fontsource`: Inter, Manrope, Unbounded), тёмная/светлая тема с персистом.

**Реализовано:**
- **Каталог** (`/`): Hero с фото и статистикой, бегущая строка происхождений (Marquee),
  сетка карточек товаров, тулбар с сортировкой.
- **Фильтры** (`useFilters`): поиск, категории (Зерно/Дрип/Техника/Наборы, мультивыбор),
  обжарка (светлая/средняя/тёмная), слайдер макс. цены (до 3500 ₽), рейтинг, 5 сортировок.
- **Карточка товара** (`/product/:id`): фото, происхождение, рейтинг, характеристики
  (обжарка/метод/вес), теги, похожие товары, «в корзину»; состояние «не найдено».
- **Корзина**: Context + `useReducer` + `localStorage`, drawer с количеством/удалением/подытогом.
- **Бренд-элементы:** `BeanMark` (лого-зерно), `AnnouncementBar`, `RoastMeter` (шкала обжарки),
  reveal-анимации и «магнитные» кнопки, grain-текстура.
- **Данные:** 12–14 товаров с реальными фото (`/public/img/*.jpg`), модель `Product`
  (origin, roast, method, weight, tags, price ₽, rating, sales).

**Сильные стороны:** цельный премиум-бренд, живой интерактив, чистая архитектура состояния,
адаптив, self-hosted шрифты (нет внешних зависимостей).

**Пробелы (что закрывает это ТЗ):**
- Нет **даты обжарки/свежести**, **выбора помола и веса** (вариантов товара).
- Нет **профиля вкуса** (шкалы/ноты/колесо) — только теги.
- Нет **подписки**, **квиза-подбора**, **страницы оформления заказа** (только drawer).
- Нет **контентных страниц** (гайды, «как обжариваем», о доставке) — ссылки ведут в никуда.
- Каталог без **URL-состояния фильтров** (нельзя расшарить ссылку с фильтром), без пагинации/«показать ещё».
- Нет **SEO-разметки** (schema.org Product), **избранного**, **пустых/загрузочных состояний** уровня продакшена.

## 5. Концепция уникальности — 6 отличий «КРЕМЫ»

Приоритетные фичи, которые делают продукт узнаваемым и конверсионным:

1. **Свежесть как фича.** Поле `roastDate` у товара + компонент «Обжарено N дней назад» и
   бейдж «Свежая обжарка» (≤ 14 дней). На карточке товара — строка «Ближайшая обжарка: вторник».
2. **Конструктор покупки.** Выбор **помола** (в зёрнах / эспрессо / фильтр / турка / гейзер) и
   **веса** (250 г / 1000 г) — варианты с пересчётом цены. Влияет на позицию в корзине.
3. **Вкусовая прозрачность.** Профиль вкуса: ноты (`flavorNotes`) + шкалы
   **кислотность / плотность / сладость** (1–5) в виде мини-баров, и интерактивное
   **вкусовое колесо** (SVG) с подсветкой нот товара.
4. **Подписка на кофе.** Интервал (2 / 4 недели), выбор «мой вкус» или «сюрприз от обжарщика»,
   скидка за регулярность. Отдельный флоу и точка входа с карточки/подвала.
5. **Квиз «Найди свой кофе».** 4–5 шагов (метод заваривания, вкус: ягодный/ореховый/шоколадный,
   крепость, с молоком/без) → подборка 2–3 товаров. Снимает страх выбора у новичка.
6. **Контент и сторителлинг.** Раздел «Гайды по завариванию» (V60, аэропресс, турка) и
   «Как мы обжариваем» + карточки происхождения (ферма/регион/высота/обработка). Обучающий
   контент — драйвер доверия и премиальности.

> Минимально-жизнеспособная уникальность (must для v1): **1, 2, 3**. Фичи **4, 5, 6** — v2.

## 6. Функциональные требования

Формат: **US** (пользовательская история) + **AC** (критерии приёмки). Все тексты — на русском,
тональность бренда — тёплая, экспертная, без канцелярита (см. 10.2).

### 6.1. Каталог (`/`)
- **US:** как покупатель, я хочу быстро найти подходящий кофе среди ассортимента.
- **AC:**
  - Hero с оффером, CTA «В каталог» (скролл к `#catalog`) и «Как обжариваем» (→ гайд).
  - Сетка карточек: 3 колонки (desktop) → 2 (планшет) → 1 (мобайл), без переполнения.
  - Тулбар: заголовок с счётчиком результатов + сортировка (5 вариантов).
  - При >12 товаров — «Показать ещё» или пагинация (не бесконечный скролл без контроля).
  - Пустое состояние при отсутствии результатов с кнопкой «Сбросить фильтры».

### 6.2. Карточка товара (`/product/:id`)
- **US:** как покупатель, я хочу понять вкус и свежесть и выбрать помол/вес перед покупкой.
- **AC:**
  - Галерея фото (минимум 1, поддержка 2–4), sticky на desktop.
  - Блок: категория, название, происхождение, рейтинг+продажи, **дата обжарки/свежесть**.
  - **Профиль вкуса:** ноты + 3 шкалы (кислотность/плотность/сладость) через `RoastMeter`-подобные бары.
  - **Селектор помола** (сегменты) и **веса** (250/1000 г) с пересчётом цены; выбранные
    параметры уходят в корзину и отображаются в позиции.
  - CTA «В корзину» (состояние «в корзине ✓»), цена, характеристики (обжарка/метод/вес/обработка).
  - Блок «Похожие» (та же категория, 3 шт). Состояние «товар не найден» для битой ссылки.
  - **schema.org/Product** микроразметка (name, image, offers, aggregateRating).

### 6.3. Фильтры, поиск, сортировка
- **US:** как энтузиаст, я хочу отфильтровать по обжарке/методу/цене и поделиться ссылкой на выборку.
- **AC:**
  - Фильтры: поиск (по названию/происхождению/нотам), категория (мультивыбор), **обжарка**,
    **метод заваривания**, слайдер цены, рейтинг. Счётчики у категорий.
  - Новое: **синхронизация фильтров с URL** (query-параметры) — состояние шарится и переживает refresh.
  - Кнопка «Сбросить» с числом активных фильтров; на мобайле — фильтры в выезжающей панели.
  - Результаты пересчитываются мгновенно (derived state, без запроса).

### 6.4. Корзина и оформление заказа
- **US:** как покупатель, я хочу собрать заказ и оформить его за понятные шаги.
- **AC:**
  - Drawer-корзина: позиции с фото/помолом/весом/количеством/удалением, подытог, порог
    бесплатной доставки (прогресс «до бесплатной доставки осталось N ₽»).
  - **Страница/шаги оформления** (`/checkout`): контакты, доставка (СДЭК/Почта/самовывоз —
    выбор), способ оплаты (демо), промокод, сводка. Валидация полей без `alert()` (инлайн-ошибки).
  - Экран «Заказ оформлен» с номером (демо-режим явно помечен, без реальной оплаты в v1).
  - Персист корзины в `localStorage`; корректные пустые состояния.

### 6.5. Подписка (v2)
- **AC:** выбор товара/«сюрприз», интервал (2/4 недели), помол, отображение скидки и даты
  следующей отправки; точка входа с карточки и из подвала; страница `/subscription`.

### 6.6. Квиз-подбор «Найди свой кофе» (v2)
- **AC:** 4–5 шагов с прогрессом, ветвление по ответам, итог — 2–3 рекомендованных товара
  с кнопкой «в корзину»; доступен с Hero и отдельным роутом `/quiz`.

### 6.7. Контент-страницы (v2)
- **AC:** «Гайды по завариванию» (V60/аэропресс/турка — шаги, тайминги), «Как мы обжариваем»,
  «Доставка и оплата», страница происхождения. Все ссылки в шапке/подвале ведут на реальные страницы
  (ноль «мёртвых» `href="#"`).

### 6.8. Глобальные элементы
- **AC:** Announcement-bar (закрываемый, состояние в `localStorage`), шапка (лого, навигация,
  тема, корзина с бейджем), подвал с рабочими ссылками, **тема dark/light** с персистом
  (dark — по умолчанию), scroll-to-top при навигации.

## 7. Дизайн-требования

- **Бренд/палитра (сохранить и развить):** фон «эспрессо» `#1a130d` / панель `#241a12`,
  акцент карамель `#c8863c` (+ `#dda85e`, deep `#a76a2c`), текст-крем `#f0e8d9`. Светлая тема — кремовая.
- **Типографика:** Unbounded (дисплей/заголовки), Inter (интерфейс), Manrope (текст). Иерархия
  H1 `clamp` крупная, ясные уровни H2/H3, тело `line-height ~1.6`.
- **Компоненты:** карточки товара, `RoastMeter`, вкусовые бары, вкусовое колесо, селекторы
  помола/веса, чипы нот, бейдж свежести, drawer, степпер количества, шаги чекаута/квиза.
- **Состояния (обязательно):** hover/active/focus-visible, disabled, загрузка (скелетоны),
  пусто, ошибка. Контраст текста — проверить в **обеих** темах (муты не должны «пропадать» в светлой).
- **Motion:** микровзаимодействия 150–250 мс, reveal 400–600 мс; всё под
  `prefers-reduced-motion: reduce`. Анимации только `transform/opacity` (GPU).
- **Фото:** единый стиль (тёплый, тёмный фон, макро зерна/чашки), одинаковый аспект в сетке.

## 8. Нефункциональные требования

- **Производительность:** Lighthouse (mobile) Performance ≥ 90; LCP < 2.5 c; изображения
  оптимизированы (WebP/AVIF, корректные размеры, `loading="lazy"` ниже 1-го экрана,
  `width/height` против CLS); JS-бандл разумный (code-splitting по маршрутам при росте).
- **Доступность (WCAG 2.1 AA):** семантика, `lang="ru"`, `aria-label` на иконочных кнопках,
  `aria-live` для динамики (счётчик корзины/результатов), фокус-ловушка в drawer/модалках,
  навигация с клавиатуры, контраст ≥ 4.5:1 для текста.
- **SEO:** уникальные `<title>`/`<meta description>` по страницам (react-helmet или аналог),
  OG-теги, `schema.org/Product`, человекочитаемые URL, `sitemap.xml`, `robots.txt`.
- **Адаптив:** брейкпоинты 480 / 768 / 1024; ноль горизонтального переполнения на 360–1440 px.
- **Совместимость:** актуальные Chrome/Firefox/Safari/Edge + мобильные Safari/Chrome.
- **Качество:** ноль ошибок/предупреждений в консоли; проходит `tsc` и линтер; прод-сборка зелёная.
- **Аналитика (опц.):** события add_to_cart / begin_checkout / view_item (заглушка-обёртка).

## 9. Технические требования

- **Стек:** сохранить React 19 + Vite + TypeScript + SCSS-модули + React Router. Fonts — `@fontsource`.
  Для сложных переходов допустим `framer-motion`. **Без** тяжёлых UI-китов и внешних API для core-UI.
- **Архитектура:** компоненты в `components/`, экраны в `pages/`, состояние домена в `context/`
  и `hooks/`, данные — в `data/` за абстракцией (см. слой данных). Логика хранилища отделена от рендера.
- **Модель данных — расширить `Product`:**
  ```ts
  roastDate: string;              // ISO — дата обжарки (для свежести)
  grinds: Grind[];                // ['whole','espresso','filter','turkish','geyser']
  weights: { g: number; price: number }[]; // варианты веса/цены
  flavorNotes: string[];          // ноты вкуса
  profile: { acidity: 1..5; body: 1..5; sweetness: 1..5 };
  process?: 'washed'|'natural'|'honey';
  altitude?: string;              // напр. «1900–2100 м»
  producer?: string;              // ферма/кооператив
  stock?: number;                 // остаток / доступность
  ```
  Позиция корзины хранит `productId + grind + weightG + qty` (варианты — разные позиции).
- **Слой данных:** сейчас — статический массив; спроектировать доступ через один модуль
  (`getProducts/getProduct`), чтобы позже заменить на API/CMS без переписывания UI.
  (Опциональный трек: headless-CMS/JSON-API + реальная оплата — вне scope v1, но не ломать под него.)
- **Роутинг:** `/`, `/product/:id`, `/checkout`, (v2) `/subscription`, `/quiz`, `/guides`,
  `/guides/:slug`, `/about`, `/delivery`, `*` → 404. Фильтры каталога — в query-параметрах.
- **Деплой:** Vercel (SPA-rewrite уже есть в `vercel.json`) — предпочтительно (чистый роутинг),
  либо GitHub Pages с `404.html`-fallback и `base`. CI: `tsc -b && vite build` должен проходить.
- **i18n-ready:** тексты выносить так, чтобы позже добавить EN-версию (не хардкодить вперемешку).

## 10. Контент-требования

- **10.1. Каталог:** минимум **16–20** товаров с реальными фото единого стиля; заполнить все
  новые поля (даты обжарки, ноты, профиль, помолы, веса). Категории: Зерно, Дрип, Техника, Наборы.
- **10.2. Тон текстов:** тёплый, экспертный, человеческий; про вкус и происхождение, без
  канцелярита и штампов. Описания товара — 2–4 предложения о вкусе и как заваривать.

## 12. Definition of Done / чеклист приёмки

Фича считается готовой, когда:
- [ ] Соответствует AC своего раздела; работает во всех заявленных состояниях (hover/focus/disabled/loading/empty/error).
- [ ] Адаптив 360–1440 px без горизонтального переполнения; проверено на 375 / 768 / 1280.
- [ ] Обе темы: контраст в норме, ничего не «пропадает».
- [ ] Доступность: клавиатура, фокус, `aria`, контраст ≥ 4.5:1.
- [ ] Ноль ошибок/предупреждений в консоли; `tsc` и линтер зелёные; `vite build` проходит.
- [ ] `prefers-reduced-motion` уважается; анимации на `transform/opacity`.
- [ ] Нет «мёртвых» `href="#"`; все ссылки ведут на реальные экраны/действия.
- [ ] Lighthouse (mobile): Performance ≥ 90, Accessibility ≥ 95.
- [ ] Изменения в git отдельными осмысленными коммитами.
